외국어 유튜브 강의로 이중 언어 노트를 만들려면 Damas에서 원래 언어의 받아쓰기와 번역문을 준비한 뒤, 개념마다 근거와 자신의 설명을 정리하세요. 한 언어를 가리고 설명한 다음 반대 방향도 시도합니다. 막히는 부분이 표현인지 개념의 관계인지 구분해 다음에 복습할 대목을 고릅니다. 노트 작성과 연습은 직접 하는 작업이며 자동 채점 기능이 아닙니다.

## 같은 강의의 원문과 번역문 준비하기

Damas는 최대 90분의 YouTube, Instagram, X 공개 주문형 영상 중 지원되는 링크를 처리합니다. iPhone에서는 iOS 18.6 이상, 인터넷, Premium과 AI 처리 동의가 필요합니다. 처리 권한이 있는 자료만 사용하세요. 비공개, 접근 제한, 실시간 영상은 지원하지 않으며 공개 원본도 처리 시 접근하지 못할 수 있습니다.

1. 강의를 열고 원본 링크와 제목, 설명할 수 있게 되고 싶은 질문을 적으세요.
2. 지원되는 링크를 Damas에 입력하고 현재 앱 안내에 따라 원래 언어의 받아쓰기와 지원되는 학습 언어로의 번역을 진행하세요. AI 동의를 읽으세요.
3. 처리가 끝나면 필요에 따라 앱 내 요약으로 전체 흐름을 파악하세요. 근거는 짧은 개요가 아닌 완전한 발언에서 찾습니다.
4. 이름, 용어, 수치, 부정과 조건을 음성에서 확인하고 번역 의미도 검토한 뒤 편집하고 복사하세요. 원래 언어를 판단하기 어렵다면 두 언어에 능숙한 사람의 검토 전까지 보류합니다.
5. 앞뒤 내용으로 같은 개념을 다루는 원문과 번역 부분을 찾아 자신의 문서에 나란히 놓으세요. 문단 경계가 같다고 가정하지 않습니다.

번역 대상 70개 언어와 인터페이스 11개 언어는 별도 목록입니다. 함께 표시된 실제 iPhone 이미지는 영어 인터페이스의 받아쓰기 화면이며 이중 언어 노트나 연습 화면이 아닙니다.

## 단어 쌍보다 하나의 설명을 기록하기

개념마다 학습 질문, 확인한 원문, 대응 번역, 자신의 설명, 적용 조건과 남은 질문을 적으세요. 직접 인용은 원음을 단어마다 확인하고, 자신의 설명과 번역에는 각각 표시를 붙입니다. 강의에 없는 설명이나 예시를 강연자의 발언에 덧붙이지 마세요.

개념 사이의 관계까지 적으세요. 무엇과 무엇을 비교하며 어떤 조건에서 결론이 성립하는지 답하는 형식이 좋습니다. 용어의 번역을 안다고 그 관계를 설명할 수 있는 것은 아닙니다. 화면에만 나온 도표나 수식은 직접 확인해 시각 정보라고 표시하세요. 확인할 수 없는 항목은 빈칸의 이유를 남깁니다.

## 양방향 설명으로 다음 복습 정하기

먼저 원문만 보고 번역을 가린 채 학습 언어로 설명하세요. 자신의 첫 답을 보관한 뒤 검토한 번역과 비교해 빠진 조건을 표시합니다. 다음에는 자신의 설명만 보고 원래 언어로 같은 관계를 짧게 설명해 보세요. 원문의 어순을 그대로 암기할 필요는 없습니다.

| 시도에서 관찰한 것 | 다음에 볼 부분 |
| --- | --- |
| 학습 언어로 설명할 수 있지만 원어가 떠오르지 않음 | 해당 표현을 문맥과 함께 복습합니다. 개념을 모른다고 바로 단정하지 않습니다. |
| 두 언어 모두에서 관계를 설명하기 어려움 | 정의, 근거 문단과 강의의 예시로 돌아갑니다. 단어 교체만으로 해결하지 않습니다. |
| 자신의 답에서 근거의 조건이 달라짐 | 근거를 다시 듣고 조건을 유지해 설명을 고칩니다. |
| 원음이나 번역 자체가 미확인임 | 자료 검토 상태와 연습 결과를 따로 적습니다. |

이는 다음 학습 작업을 고르는 기준이며 언어 능력이나 이해도를 객관적으로 측정하지 않습니다. 양방향으로 설명해도 원래 주장의 진실성을 증명하는 것은 아닙니다.

## 가상 예시: 평균 비교에서 빠진 조건

실제 강의 인용이 아닌 설명용 가상 예시입니다. 강의가 평균을 비교하기 전에 측정 단위를 맞춰야 한다고 설명한다고 가정합니다. 실제 노트에는 자신의 강의가 뒷받침하는 내용만 적으세요.

- 질문: 두 평균을 비교하기 전에 무엇을 확인하는가?
- 첫 설명: 숫자의 크기를 비교한다. 단위 조건이 빠졌습니다.
- 수정: 근거 발언으로 돌아가 단위를 맞춘다는 조건을 더합니다.
- 다음 시도: 한국어로 조건을 설명해도 원래 언어의 표현이 떠오르지 않으면 해당 표현을 문맥과 함께 복습합니다. 개념의 빈틈과 표현의 빈틈을 같은 표시로 묶지 않습니다.

수정 전 답, 수정 후 답, 다시 볼 근거를 함께 보관하세요. 자신이 만든 숫자를 강의의 예시로 돌리지 말고 원본에 없는 사실, 인용문, 담당자나 기한을 만들지 마세요.

## 선택 사항: 다른 LLM에서 초안 만들기

직접 작성해도 됩니다. 다른 서비스에 공유할 권한이 있을 때만 확인한 텍스트를 복사하세요. 외부 초안 작성이며 Damas 연동이나 자동 학습 기능이 아닙니다. 복사용 예시:

> 아래 원문과 번역만으로 개념 하나에 대한 이중 언어 노트를 작성해 주세요. 질문, 근거 원문, 대응 번역, 조건을 유지한 설명과 미확인 사항을 나누세요. 양방향 설명 연습의 질문도 넣으세요. 외부 지식, 가상의 예시나 인용은 추가하지 말고 답이 없으면 ‘언급 없음’으로 쓰세요. 이해도를 채점하지 마세요. 출처: [링크]. 원문: [텍스트]. 번역: [텍스트].

모든 대응과 설명을 원본에서 확인하고 근거 없는 제안을 삭제하세요. 최종 노트에 원본 링크, 제목, 검토 상태와 다시 볼 부분을 남깁니다. 원본에 접근할 수 없으면 미완료 검토는 보류합니다.

전체 흐름은 [요약 안내](/ko/guides/summarize-video-transcript-iphone/), 대상 언어는 [번역 안내](/ko/guides/translate-social-video-iphone/)를 참고하세요. 자료의 의미가 불확실하면 연습 전에 [원문과 번역 비교](/ko/guides/transcript-translation-meaning-check/)를 진행하세요. Damas에서 읽고 편집하고 복사할 수 있는 텍스트를 준비하면 근거로 돌아가며 노트를 만들 수 있습니다.

처리 시간과 정확도는 원본, 음성, 연결에 따라 달라집니다. 미디어 다운로드, 파일 가져오기, 더빙, 자막 삽입과 오프라인 처리는 지원되지 않습니다. Premium도 접근 제한을 우회하지 못하며 공유 시 재사용 권한을 지켜야 합니다.
