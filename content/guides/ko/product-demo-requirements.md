제품 데모 영상을 내 요구 사항에 맞춰 정리하려면 Damas로 받아쓰기와 앱 내 요약을 준비한 뒤, 각 요구 사항을 실제 시연과 비교하세요. 화면으로 확인한 결과, 말로만 한 설명, 아직 시험하지 않은 조건을 구분합니다. 비교표는 직접 만드는 검토 기록이며 Damas의 자동 평가나 제품 적합성 보장이 아닙니다.

## 원본과 요구 사항 준비하기

Damas는 최대 90분인 YouTube, Instagram, X의 지원되는 공개 녹화 영상 링크를 처리합니다. iPhone에서는 iOS 18.6 이상, 인터넷, Premium, AI 처리 동의가 필요합니다. 처리 권한이 있는 자료만 사용하세요. 비공개, 접근 제한, 라이브 영상은 지원하지 않으며 공개 자료도 처리 과정에서 접근할 수 없을 수 있습니다.

1. 요약을 읽기 전에 요구 사항을 적으세요. 어떤 입력으로 어떤 조건에서 무엇이 되어야 하나요? 이것은 내 기준이며 발표자의 약속이 아닙니다.
2. 원본 링크와 제목을 보관하세요. 지원 링크를 Damas에 입력하고 AI 동의를 검토한 뒤 현재 앱의 받아쓰기 및 내장 요약 안내를 따르세요.
3. 처리가 끝나면 요약으로 전체 내용을 파악하고 받아쓰기에서 관련 발언 전체를 찾으세요. 이름, 숫자, 부정 표현, 조건은 원본을 다시 들으며 확인하세요.
4. 시연 화면은 직접 보세요. 음성 받아쓰기만으로 화면에서만 이루어진 조작을 입증할 수 없습니다. 시각적 관찰을 따로 표시한 뒤 확인한 텍스트를 편집하고 복사하세요.

## 요구 사항마다 판단 기록 만들기

요구 사항마다 내 합격 조건, 근거 발언 또는 화면 관찰, 시연 조건, 다음에 필요한 시험을 적으세요. 상태는 “이 예시에서 시연됨”, “설명만 있음”, “다루지 않음”, “확인 불가”로 구분합니다. 샘플 하나의 성공이 내가 사용할 모든 입력의 합격을 뜻하지는 않습니다. 이 근거 상태와 제품을 채택할 최종 결정도 따로 기록하세요.

여러 조건이 섞인 요구 사항은 나누세요. 문서가 열린다고 두 사람이 독립적으로 승인할 수 있다는 뜻은 아닙니다. 각각 별도 행을 만드세요. 뒤의 설명이 앞의 약속을 제한하면 두 발언과 좁아진 범위를 함께 남기세요. “다루지 않음”은 불가능하다는 뜻이 아니고 “설명만 있음”은 거짓이라는 뜻도 아닙니다. 둘 다 남은 확인 작업을 나타냅니다.

## 가상 예시: 문서 검토 도구

이것은 이름 없는 도구를 설명하기 위한 가상 예시입니다. Damas 기능이나 실제 시험 결과, 출처 인용이 아닙니다. 샘플 문서 하나가 열리고 발표자가 다른 형식도 지원한다고 말하지만 두 사람의 독립 승인에 관해서는 언급하지 않았다고 가정합니다.

| 내 요구 사항 | 가상 데모의 근거 | 검토 메모 |
| --- | --- | --- |
| 필요한 문서 형식 열기 | 화면에서 샘플 하나가 열림 | 이 샘플에서 시연됨. 허가된 대표 입력으로 시험한다. |
| 다른 필수 형식 처리 | 발표자의 일반적인 설명 | 설명만 있음. 해당 형식의 시연을 요청한다. |
| 두 사람의 독립 승인 | 해당 조작이나 발언이 없음 | 다루지 않음. 실패로 단정하지 말고 질문한다. |

## 다음 확인 항목 정하기

종합 점수는 필요하지 않습니다. 결정에 영향을 줄 미확인 요구 사항을 골라 구체적인 후속 질문을 작성하세요. 매끄러운 요약이 시험하지 않은 조건을 합격으로 바꿔서는 안 됩니다. 담당자, 기한, 인용문, 결과를 만들어 넣지 마세요. 원본에 접근할 수 없게 되면 끝내지 못한 확인은 미해결로 남깁니다.

표는 직접 만들 수 있습니다. 선택적으로 공유 권한이 있는 검토한 텍스트를 다른 LLM에 복사해 행의 초안을 요청할 수도 있습니다. 내 기준과 출처 발언을 분리해 제공하고 대응 관계를 모두 확인하세요. 이것은 외부 초안 작업이며 Damas 통합이나 자동 제품 시험 기능이 아닙니다.

앱 사용은 [기본 요약 절차](/ko/guides/summarize-video-transcript-iphone/)를 참고하세요. 정확한 말을 인용하기 전에는 [인용문 확인](/ko/guides/verify-interview-quotes/), 다른 사람에게 전달할 때는 [출처를 남긴 공유](/ko/guides/share-checked-video-notes/)가 도움이 됩니다.

복사한 표에 원본 링크, 검토 날짜, 남은 질문을 함께 보관하세요. 처리 시간과 정확도는 달라집니다. Damas는 미디어 다운로드, 파일 가져오기, 더빙, 자막 삽입, 오프라인 처리를 지원하지 않습니다. Premium도 접근 제한을 우회하지 못합니다. 재사용 권한 안에서만 공유하세요.
