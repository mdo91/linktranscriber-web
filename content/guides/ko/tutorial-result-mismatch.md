튜토리얼 영상과 내 결과가 다르면 검토한 Damas 받아쓰기로 마지막으로 일치한 상태와 처음 확인되는 차이를 찾으세요. 무언가를 바꾸기 전에 두 지점을 시연과 비교합니다. 이 수작업은 질문을 좁히는 방법이며 자동 원인 진단이나 복구 보장이 아닙니다.

## 설명과 원본 준비하기

Damas는 최대 90분의 YouTube, Instagram, X 공개 주문형 동영상 링크를 지원합니다. iPhone에서는 iOS 18.6 이상, 인터넷, Premium, AI 처리 동의가 필요합니다. 처리 권한이 있는 자료만 제출하세요. 비공개, 접근 제한, 실시간 영상은 지원되지 않으며 공개 영상도 접근할 수 없으면 처리에 실패할 수 있습니다.

1. 원래 플랫폼에서 튜토리얼을 열고 링크와 제목을 메모에 보관하세요.
2. 지원되는 링크를 Damas에 입력하고 현재 앱 안내에 따라 받아쓰기를 진행하세요. AI 처리 동의를 읽으세요.
3. 처리가 끝나면 불명확한 단어, 수치, 단위를 원본 오디오와 대조한 뒤 편집하고 복사하세요.
4. 시연과 화면의 표시도 확인하세요. 말로 설명하지 않은 설정은 텍스트에 없을 수 있습니다.
5. 앱 내 요약으로 전체 흐름을 파악하되 순서와 예외는 전체 설명에서 확인하세요.

## 처음 관찰되는 차이까지 돌아가기

설명되지 않는 결과 위에 다음 작업을 계속하지 마세요. 별도 메모에 기대한 결과, 실제로 본 상태, 마지막으로 시연과 일치한 지점을 적습니다. ‘복사한 표에 행이 보이지 않음’은 관찰입니다. ‘앱이 데이터를 삭제함’은 아직 확인하지 않은 원인 추측입니다.

마지막 일치 지점부터 입력 자료, 설명된 사전 조건, 행동, 화면의 결과를 내 시도와 차례로 비교하세요. ‘일치’, ‘다름’, ‘비교 불가’를 나눠 첫 차이가 확인되면 멈춥니다. 영상에 중간 결과가 없으면 비교 불가로 남기세요. 보이지 않는 상태가 일치했다고 가정하지 않습니다.

다른 입력, 놓친 안내, 불명확한 설정은 별도 칸에 조사할 가능성으로 적으세요. 원본이 조건과 해결 행동을 실제로 설명할 때만 수정 방법을 메모에 채택합니다. 설명이 없으면 조작을 만들어 내지 말고 질문을 준비하세요. 메모에서 비교하므로 데이터를 손상시킬 수 있는 작업을 반복할 필요가 없습니다.

## 가상 예시: 필터 뒤에 행이 보이지 않는 표

이것은 실제 녹화나 테스트, Damas 기능이 아닌 가상의 설명 예시입니다. 영상은 표를 복사하고 범주 필터를 적용한 뒤 몇 개의 행을 보여 줍니다. 내 표는 필터 전에는 보이지만 그 뒤에는 행이 보이지 않습니다.

| 기록 | 남길 내용 |
| --- | --- |
| 마지막 일치 | 필터 전 복사한 표가 보임. |
| 첫 차이 | 영상에는 행이 남지만 내 화면에는 없음. |
| 다음 비교 | 실제 영상의 범주 값과 시작 자료의 행. |
| 미확인 | 범주, 입력 자료, 다른 조건 중 무엇이 관련되는지. |

빈 화면만으로 삭제를 입증할 수 없습니다. 영상이 이 경우를 다루지 않으면 복구 명령을 만들지 마세요. 원본 자료를 보존하고 필요한 사전 조건을 질문합니다.

## 답할 수 있는 질문으로 정리하기

짧은 전달 메모에 링크와 제목, 작업과 검토한 근거, 내 시작 조건, 기대와 관찰, 첫 차이, 질문 하나를 넣으세요. 가상 예시라면 ‘이 예시에는 어떤 범주 값과 시작 자료가 필요한가요?’입니다. 내 관찰과 출처의 설명을 구분하고, 미검증 가능성을 튜토리얼의 오류라고 단정하지 마세요.

시도 전에는 [튜토리얼 체크리스트](/ko/guides/tutorial-checked-checklist/)로 준비하고, 정확한 말은 [인용문 확인](/ko/guides/verify-interview-quotes/)에서 점검하세요. Damas의 편집·복사 가능한 설명은 기억에만 의존하지 않고 관련 대목을 다시 읽는 데 쓰입니다.

외부 LLM은 필요하지 않습니다. 선택적으로 다른 LLM에 서식을 맡기려면 텍스트 공유 권한이 있어야 하며 제안된 원인을 모두 검토해야 합니다. Damas 통합 기능이 아닙니다. 관찰, 근거와 불확실성을 분리하고 사실, 인용, 담당자나 기한을 만들지 마세요.

최종 체크리스트에도 원본 링크를 남기세요. 처리 시간과 정확도는 달라집니다. Damas는 미디어 다운로드, 자막 삽입, 오프라인 처리를 지원하지 않습니다. Premium도 접근할 수 없는 영상을 이용 가능하게 만들지는 않습니다.
