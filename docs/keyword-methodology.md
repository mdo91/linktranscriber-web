# Damas keyword research

Launch research date: **20 October 2026**. The platform and reader-question seed expansion below was prepared on **29 October 2026**; it is a research plan, not new measured demand.

The launch guide library was refined using real Google Ads API keyword ideas and historical metrics, collected through Gum in Damas's separate keyword-research profile. Each of the eleven supported website languages was researched independently. Every request explicitly targeted **worldwide geography**, its matching Google language constant, and **Google Search**. No paid campaigns were created. The private research caches and article-to-keyword evidence remain outside the public repository.

## How topics were selected

The library answers three different supported tasks: turning a public video link into a transcript, translating video speech into readable text, and making a shorter account from a transcript. Each task has one equivalent guide in every language. Existing stable URLs, translation groups and related-guide relationships were preserved.

Returned search phrases informed titles, descriptions, topic labels and the opening answers. We selected phrases that fit the actual task rather than the largest estimate alone. For example, English results included “video link to text”; German results used “Video in Text umwandeln”; Japanese results included “動画 文字起こし”; and Turkish results used “videoyu metne çevirme.” Translation results supported natural YouTube-focused wording, while the articles also explain the same supported Instagram and X workflow. Summary guides remain separate from full transcripts and translations.

Broad video-to-text searches can mean file uploads, on-screen text recognition, or other tasks. The articles therefore state that this workflow starts with a supported public link and converts speech into text on supported iPhone, iPad and compatible Mac devices. Translation guides describe readable translated text without promising dubbing or video editing. Searches promising free processing were excluded from positioning because the described Damas workflow requires Premium.

The API supplied estimates for most selected queries, but not for Malay transcription or Portuguese and Spanish transcript summaries. Those three guides remain useful explanations of supported product workflows; their demand is **unavailable**, rather than zero or a fabricated positive estimate. Returning a requested phrase without metrics is not proof of measurable search demand.

## Interpreting the evidence

Google Keyword Planner provides estimates, not exact visitor counts. We preserve canonical phrases and close variants without adding their estimates together. A returned range remains a range. Advertising competition describes advertisers and must not be presented as organic ranking difficulty. Worldwide language targeting does not establish demand in every country or guarantee that a query will lead to app downloads.

Fresh caches are reused for up to 30 days, then refreshed. The daily growth workflow combines this demand evidence with complete Search Console reporting periods when available and inspects existing coverage before proposing an update. Search Console's average position is an aggregate. Missing performance data does not prove a page is unindexed, and unchanged pages are not refreshed merely to suggest freshness.

The three workflows across eleven locales are the launch library. The daily workflow targets one distinct new guide per language, published as one batch. It compares the full localized library before selecting an uncovered reader question. Device variants and closely related query variants are not reasons to create duplicate pages. Routine fallback updates require a 28-day cooldown and a recorded reason why no qualified new article was selected. New articles, updates and skips are reported separately; an update does not meet the new-article target. Qualified languages can publish while another language is skipped for a documented evidence or quality shortfall.

## Download-oriented selection

The private runner classifies the complete response before selecting a bounded shortlist per language. It excludes unsupported media conversion/download, dubbing, file/output and source intents. Within eligible tasks it brings uncovered practical questions forward before the shortlist is truncated, then uses supported public links, Apple-device/app relevance and estimated demand as supporting signals. An uncovered exact query is a discovery aid, not proof of a distinct intent; the editor compares complete answers. The priority is an editorial heuristic, not a predicted conversion rate or ranking guarantee. Close variants remain grouped without adding their volumes. Private manifests record the selected phrase, feature, source observation, create/update decision and any locale shortfall; independent validation binds each changed guide to that evidence.

## Platform and reader-question seed expansion

The seed lists retain the earlier lecture, study-note, tutorial-checklist, webinar, interview and device phrases. Each language now also covers transcription, translation and summaries for YouTube, Instagram and X. Local phrasing varies: for example, Japanese uses “文字起こし”, Korean uses “받아쓰기”, and X is paired with Twitter where that makes the source clearer. These are discovery phrases; adding a platform name to an answered workflow does not qualify a separate guide.

The additional questions concern speech in eligible public Instagram Reels, reading foreign speech as translated text, the difference between an original-language transcript and a translation, lectures up to 90 minutes, preserving context in X summaries, and copying checked notes with original passages and a source link. Translation seeds include the verified **70 target languages**, separate from the eleven interface languages. They do not promise translated audio, dubbing, embedded subtitles, subtitle files, downloads, file uploads, or support for live, private or restricted sources. Editing, copying and built-in summaries are supported; more specialized note structures, question-to-answer records, theme analysis and sharing in another document are manual workflows, with any external-LLM drafting identified explicitly.

The expansion also retains seven previously unqualified questions for same-language research: English webinar questions and answers and sharing checked notes with source passages; Malay, Portuguese and Russian interview themes and contradictions; and Chinese webinar action items and questions left unanswered. The Chinese action-item phrase was already a seed and remains unchanged. A seed or a competitor example does not establish demand. Each prospective article still needs eligible evidence in its own language and a distinct answer after review of the complete localized guide bodies; a translation of another language's opportunity is insufficient. An already answered question stays covered unless a qualified update is warranted.

There are 20 or 21 added phrases per language, leaving 35–37 total seeds and two batches of at most 20 seeds per language. The existing collector requests ideas and historical metrics for each batch, with pagination where supplied. Targeting remains worldwide, the matching Google language constant and Google Search. Changing a seed list changes its fingerprint and causes one fresh read-only collection per language, then the existing 30-day cache reuse. Source data and observation dates remain intact when refresh fails. A fresh authentic CSV can still supply research without requiring API access. Preparing the seed expansion itself made no research API requests and supplies no new volume estimates.

The private version-2 batch manifest records each article’s reader question, useful outcome, closest existing localized guide and distinct value. New titles must reflect that question; independent validation rejects exact/device-only question reuse, substantial copied answers and routine updates inside the cooldown. These structural checks support editorial review and do not prove semantic originality or search demand by themselves.

Articles give an early answer, verified steps, a useful original example or clearly labeled prompt, relevant limits and contextual guide/download links. Damas's built-in summaries are distinguished from optional custom work in another LLM after copying the transcript. Requirements and media provenance are documented in [product facts](product-facts.md). Do not invent first-hand testing, specific app controls, integrations or performance results.

Search Console comparisons remain separate for all 11 language routes, using complete recent and prior 28-day periods. Search clicks, Keyword Planner demand and authentic Apple campaign downloads are different measurements. Article/locale campaign links use the genuine provider token when configured; otherwise attribution remains unavailable. No analytics service or paid campaign is added.

## API metric preservation

API caches use normalization version 2 so empty idea objects cannot hide reported historical metrics. Historical values take precedence per field; known zeros and monthly entries survive empty pages, and variants are never summed. Older API caches refresh once; CSVs retain original dates. Private per-language seed audits distinguish withheld estimates from missing API evidence. Wrong-locale cache filenames are rejected. No account IDs, credentials or raw private metrics enter public guides.
